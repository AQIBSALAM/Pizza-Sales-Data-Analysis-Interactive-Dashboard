# 🍕 Pizza Sales Analysis Dashboard

## 📊 Project Overview
This project involves a comprehensive analysis of a pizza restaurant's sales data. Using **Power BI**, I transformed raw data into an interactive dashboard that provides actionable insights into sales performance, customer behavior, and product trends.

## 🎯 Key Objectives
- To calculate essential business metrics (KPIs) like Total Revenue, Average Order Value, and Sales Quantities.
- To identify peak hours and busiest days for better staff management.
- To analyze product performance (Best/Worst Sellers) to optimize the menu.

## 💡 Key Insights (From Dashboard)
- [cite_start]**Revenue Performance:** Total revenue reached **815,146** with an average order value of **38.30**[cite: 3, 4].
- [cite_start]**Sales Trends:** Orders peak on **Fridays and Saturdays**, particularly during lunch (12 PM) and evening (4 PM - 8 PM) hours[cite: 48, 64, 69].
- [cite_start]**Product Analysis:** The **Classic Category** and **Large (L) Size pizzas** are the primary revenue drivers[cite: 86].
- [cite_start]**Top Performer:** "The Italian Supreme Pizza" is the highest-selling item by order count[cite: 49].

## 🛠️ Technical Stack
- [cite_start]**Data Source:** Microsoft Excel[cite: 12].
- **Data Cleaning:** Power Query (Transforming data, fixing types, and cleaning nulls).
- **DAX Formulas:** Developed custom measures for:
  - `Avg Order Value = [Total Revenue] / [Total Orders]`
  - `Avg Pizza Per Order = [Total Pizzas Sold] / [Total Orders]`
- [cite_start]**Visuals:** Bar Charts, Pie Charts, Donut Charts, and Time-series Analysis[cite: 1].

1. Download the `.pbix` file.
2. Open it in **Power BI Desktop**.
3. Use the **Date Slicer** to filter data for specific time periods[cite: 10].
